# Ejercicio 4.3 — Fake vs. Mock (8 pts)

## Objetivo

Elegir correctamente entre un fake y un mock según el contexto.

## Instrucciones

1. Crea `tests/Unit/Application/CrearBilleteraConMocksTest.php`:
   - Mock de `BilleteraRepository` con `createMock`
   - Mock de `MessageBusInterface` con `expects($this->once())`
   - Verifica que `save()` se llama exactamente 1 vez
   - Verifica que `dispatch()` recibe un `BilleteraCreadaEvent`

2. Compara con el test existente `CrearBilleteraCommandHandlerTest.php` (usa fakes):
   - ¿Cuál es más legible?
   - ¿Cuál es más fácil de mantener si cambia la interfaz?

3. Añade un comentario en el código indicando POR QUÉ usaste mock en este caso.

## Verificación

```bash
./vendor/bin/phpunit tests/Unit/Application/CrearBilleteraConMocksTest.php --testdox
# Deben pasar 3 tests
```
