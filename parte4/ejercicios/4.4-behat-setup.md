# Ejercicio 4.4 — Behat setup (7 pts)

## Objetivo

Instalar y configurar Behat con Symfony.

## Instrucciones

1. Instala Behat con la extensión de Symfony:
   ```bash
   composer require --dev behat/behat friendsofbehat/symfony-extension
   ```

2. Crea `behat.yml` (usar la solución como referencia).

3. Crea `features/` y verifiqua que Behat bootea:
   ```bash
   ./vendor/bin/behat --init
   ```

4. Verifica que el contexto se carga:
   ```bash
   ./vendor/bin/behat --format=pretty --dry-run
   # Debe mostrar los escenarios SIN ejecutarlos
   ```

## Verificación

```bash
./vendor/bin/behat --dry-run
# Debe mostrar: ~4 escenarios reconocidos, 0 failures (dry-run)
```
