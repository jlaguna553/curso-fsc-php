# Ejercicio 4.6 — Cobertura (7 pts)

## Objetivo

Alcanzar 100% de cobertura en `src/Domain/` con PCOV.

## Instrucciones

1. Instala PCVDocker Compose:
   ```bash
   docker compose exec php-fpm pecl install pcov
   docker compose exec php-fpm docker-php-ext-enable pcov
   ```

2. Ejecuta con cobertura:
   ```bash
   ./vendor/bin/phpunit --testsuite unit --coverage-html=coverage --coverage-text
   ```

3. Abre `coverage/index.html` y busca archivos en `src/Domain/` con < 100%.

4. Para cada archivo sin 100%, añade el test que cubra la línea faltante.

## Verificación

```bash
./vendor/bin/phpunit --testsuite unit --coverage-text | grep "src/Domain/"
# Cada archivo debe mostrar: 100.0%
```

## Puntos: 7
