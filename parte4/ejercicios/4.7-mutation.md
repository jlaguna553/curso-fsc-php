# Ejercicio 4.7 — Mutational testing (10 pts)

## Objetivo

Detectar mutantes vivos con Infection y elevar el MSI a 85%.

## Instrucciones

1. Instala Infection:
   ```bash
   composer require --dev infection/infection
   ```

2. Crea `infection.json5` en la raíz del wallet-service:
   ```json
   {
       "source": { "directories": ["src/Domain"] },
       "logs": { "text": "infection.log" },
       "minMsi": 85,
       "minCoveredMsi": 90
   }
   ```

3. Ejecuta Infection:
   ```bash
   ./vendor/bin/infection --show-mutations
   ```

4. Para cada **mutante vivo** (sobreviviente), escribe un test que lo mate.

## Verificación

```bash
./vendor/bin/infection --show-mutations 2>&1 | grep " MSI:"
# MSI: 85% o superior
# Cada mutante debe mostrar "KILLED" o "NOT COVERED"
```

## Puntos: 10
