# Ejercicio 0.5: Flujo de Trabajo con Git

## Objetivo

Practicar Conventional Commits y el ciclo TDD básico con Git.

## Instrucciones

### Paso 1: Crear repositorio

Crea un directorio `mi-primer-repo`, inicializa Git y renombra la rama
principal a `main`.

### Paso 2: Primer commit (docs)

Crea un archivo de bienvenida (`hola.txt`), agrégalo al index y haz tu
primer commit con un mensaje en formato Convencional de tipo `docs:`.

### Paso 3: Segundo commit (feat)

Escribe en `suma.php` una función `sumar(int $a, int $b): int` con
`declare(strict_types=1)` y docblock. Commitea con un mensaje `feat:`.

### Paso 4: Tercer commit (test)

Escribe `test-suma.php` que cargue `suma.php` y pruebe al menos 3 casos
(positivos, con cero, negativos) usando `assert()`. Commitea con `test:`.

### Paso 5: Ejecutar el test

Ejecuta `php test-suma.php` y confirma que los 3 casos pasan.

### Paso 6: Cuarto commit (refactor)

Mejora `suma.php` añadiendo protección de overflow/underflow: lanza
`\OverflowError` si la suma excedería `PHP_INT_MAX`, o `\UnderflowError`
si quedaría debajo de `PHP_INT_MIN` — sin cambiar el comportamiento para
entradas normales. Commitea con `refactor:`.

### Paso 7: Verificar que los tests siguen pasando

Re-ejecuta `php test-suma.php`: debe seguir pasando igual que antes.

### Paso 8: Ver el historial

Consulta el historial con `git log --oneline --graph`.

## Entregable

Captura del historial de Git con al menos 4 commits con mensajes
Convencionales.

## Verificación

- `git log --oneline --graph` muestra al menos 4 commits.
- Los mensajes usan los prefijos `docs:`, `feat:`, `test:` y `refactor:`.
- `php test-suma.php` confirma que los tests pasan tras el refactor.

```bash

/**
```

*Paso 4 (`test-suma.php`):*

```bash
cat > test-suma.php << 'EOF'
<?php

declare(strict_types=1);

require 'suma.php';

// Test case 1: suma positiva
$resultado1 = sumar(2, 3);
$esperado1 = 5;
assert($resultado1 === $esperado1, "Esperaba $esperado1, obtuve $resultado1");

// Test case 2: suma con cero
$resultado2 = sumar(10, 0);
$esperado2 = 10;
assert($resultado2 === $esperado2, "Esperaba $esperado2, obtuve $resultado2");

// Test case 3: suma de negativos
$resultado3 = sumar(-5, -3);
$esperado3 = -8;
assert($resultado3 === $esperado3, "Esperaba $esperado3, obtuve $resultado3");

echo "✓ 3 tests pasaron correctamente" . PHP_EOL;
EOF

git add test-suma.php
git commit -m "test: agregar tests de la función sumar"
```

*Paso 6 — refactor con protección de overflow/underflow:*

```bash
cat > suma.php << 'EOF'
<?php

declare(strict_types=1);

/**
 * Suma dos enteros de forma segura.
 *
 * @param int $a Primer sumando
 * @param int $b Segundo sumando
 * @return int La suma de $a + $b
 *
 * @throws \OverflowError Si la suma excede PHP_INT_MAX
 * @throws \UnderflowError Si la suma es menor que PHP_INT_MIN
 */
function sumar(int $a, int $b): int
{
    // Verificar overflow antes de la operación
    // Si $a > 0 y $b > PHP_INT_MAX - $a, habrá overflow
    if ($b > 0 && $a > PHP_INT_MAX - $b) {
        throw new \OverflowError("La suma de $a + $b excede PHP_INT_MAX");
    }

    // Verificar underflow antes de la operación
    if ($b < 0 && $a < PHP_INT_MIN - $b) {
        throw new \UnderflowError("La suma de $a + $b es menor que PHP_INT_MIN");
    }

    return $a + $b;
}
EOF

git add suma.php
git commit -m "refactor: agregar protección de overflow en función sumar"

php test-suma.php
# Salida: ✓ 3 tests pasaron correctamente (¡sigue pasando!)
```
