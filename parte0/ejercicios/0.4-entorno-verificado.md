# Ejercicio 0.4: Verificar tu Entorno

## Objetivo

Confirmar que tu máquina tiene todas las herramientas necesarias para el curso.

## Instrucciones

1. Ejecuta el verificador de entorno:

```bash
bash parte0/scripts/doctor.sh
```

2. Verifica que el veredicto sea `READY`.

3. Guarda la salida completa:

```bash
bash parte0/scripts/doctor.sh > evidencia-entorno.txt 2>&1
```

## Entregable

Archivo `evidencia-entorno.txt` con la salida completa del script doctor.sh
que muestre `"verdict": "READY"`.

## Puntos

| Criterio | Puntos |
|---|---|
| PHP 8.3+ instalado | 2 |
| Composer 2.7+ instalado | 1 |
| Symfony CLI instalado | 1 |
| Git configurado (user + email) | 1 |
| Docker instalado y corriendo | 2 |
| **Total** | **7** |
