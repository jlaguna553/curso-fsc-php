# Ejercicio 0.3: Validar un Contrato JSON

## Objetivo

Aprender a validar contratos JSON entre servicios usando herramientas de línea
de comandos, una habilidad crítica para debugging en microservicios.

## Contexto

Cuando dos microservicios se comunican por JSON, un campo malformado puede causar
errores silenciosos. En fintech, esto puede significar dinero perdido.

## Instrucciones

### Paso 1: Instalar jq

```bash
# macOS
brew install jq

# Ubuntu/Debian
sudo apt install jq

# Windows (WSL2)
sudo apt install jq
```

### Paso 2: Crear el archivo de prueba

```bash
cat > transaccion-request.json << 'EOF'
{
  "monto": "1500.00",
  "moneda": "MXN",
  "tipo": "deposito",
  "billetera_id": "wallet_x1y2z3",
  "idempotency_key": "dep_unique_abc123"
}
EOF
```

### Paso 3: Validaciones con jq

```bash
# Validar que monto es string (no number)
# type identifica el tipo JSON: "string", "number", "object", etc.
cat transaccion-request.json | jq 'if (.monto | type) == "string" then "monto: OK (string)" else "monto: ERROR (no es string)" end'
# Salida: monto: OK (string)

# Validar longitud de moneda (exactamente 3 caracteres)
cat transaccion-request.json | jq 'if (.moneda | length) == 3 then "moneda: OK (3 chars)" else "moneda: ERROR (esperaba 3 chars)" end'
# Salida: moneda: OK (3 chars)

# Validar tipo sea uno de los valores permitidos
cat transaccion-request.json | jq 'if .tipo as $t | ["deposito","retiro","transferencia"] | index($t) then "tipo: OK" else "tipo: ERROR (valor no permitido)" end'
# Salida: tipo: OK

# Validar que idempotency_key no esté vacío
cat transaccion-request.json | jq 'if (.idempotency_key | length) > 0 then "idempotency_key: OK" else "idempotency_key: ERROR (vacío)" end'
# Salida: idempotency_key: OK
```

### Paso 4: Script completo de validación

```bash
cat > validar-contrato.sh << 'SCRIPT'
#!/usr/bin/env bash
# validar-contrato.sh — Valida el contrato JSON de una transacción
# Uso: bash validar-contrato.sh archivo.json

set -euo pipefail

# Verificar que se proporcionó un archivo
if [[ $# -ne 1 ]]; then
    echo "Uso: $0 <archivo.json>"
    exit 1
fi

FILE="$1"

# Verificar que el archivo existe y es JSON válido
if [[ ! -f "$FILE" ]]; then
    echo "CONTRATO INVÁLIDO: Archivo no encontrado: $FILE"
    exit 1
fi

if ! jq empty "$FILE" 2>/dev/null; then
    echo "CONTRATO INVÁLIDO: JSON malformado"
    exit 1
fi

ERRORS=()

# Validar que monto sea string
MONTO_TYPE=$(jq -r '.monto | type' "$FILE")
if [[ "$MONTO_TYPE" != "string" ]]; then
    ERRORS+=("monto debe ser string, no $MONTO_TYPE")
fi

# Validar que monto sea un número positivo
MONTO_VAL=$(jq -r '.monto' "$FILE")
if ! echo "$MONTO_VAL" | grep -qE '^[0-9]+(\.[0-9]+)?$'; then
    ERRORS+=("monto '$MONTO_VAL' no tiene formato numérico válido")
fi

# Validar que moneda tenga 3 caracteres
MONEDA_LEN=$(jq -r '.moneda | length' "$FILE")
if [[ "$MONEDA_LEN" -ne 3 ]]; then
    ERRORS+=("moneda debe tener exactamente 3 caracteres (tiene $MONEDA_LEN)")
fi

# Validar tipo sea uno de los permitidos
TIPO=$(jq -r '.tipo' "$FILE")
case "$TIPO" in
    deposito|retiro|transferencia) ;; # OK
    *) ERRORS+=("tipo '$TIPO' no es válido (usar: deposito, retiro, transferencia)") ;;
esac

# Validar que idempotency_key no esté vacío
KEY_LEN=$(jq -r '.idempotency_key | length' "$FILE")
if [[ "$KEY_LEN" -eq 0 ]]; then
    ERRORS+=("idempotency_key no puede estar vacío")
fi

# Resultado
if [[ ${#ERRORS[@]} -eq 0 ]]; then
    echo "CONTRATO VÁLIDO"
    exit 0
else
    echo "CONTRATO INVÁLIDO:"
    for err in "${ERRORS[@]}"; do
        echo "  - $err"
    done
    exit 1
fi
SCRIPT

chmod +x validar-contrato.sh
```

### Paso 5: Probar con datos válidos e inválidos

```bash
# Caso válido
bash validar-contrato.sh transaccion-request.json
# Salida: CONTRATO VÁLIDO

# Caso inválido: monto numérico
echo '{"monto": 1500, "moneda": "MXN", "tipo": "deposito", "billetera_id": "w1", "idempotency_key": "k1"}' > invalido.json
bash validar-contrato.sh invalido.json
# Salida: CONTRATO INVÁLIDO: monto debe ser string, no number

# Caso inválido: moneda de 2 caracteres
echo '{"monto": "100", "moneda": "US", "tipo": "deposito", "billetera_id": "w1", "idempotency_key": "k1"}' > invalido2.json
bash validar-contrato.sh invalido2.json
# Salida: CONTRATO INVÁLIDO: moneda debe tener exactamente 3 caracteres (tiene 2)

# Caso inválido: tipo incorrecto
echo '{"monto": "100", "moneda": "MXN", "tipo": "cargo", "billetera_id": "w1", "idempotency_key": "k1"}' > invalido3.json
bash validar-contrato.sh invalido3.json
# Salida: CONTRATO INVÁLIDO: tipo 'cargo' no es válido
```

## Entregable

Archivos:
- `validar-contrato.sh` (ejecutable)
- `transaccion-request.json` (datos de prueba)
