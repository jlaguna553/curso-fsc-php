# Ejercicio 0.1: Practicar Peticiones HTTP

## Objetivo

Familiarizarte con `curl` y los métodos HTTP fundamentales (GET, POST), y
extraer campos de una respuesta JSON con `jq`.

## Contexto

En PrestaFlow, los microservicios se comunican exclusivamente por HTTP/JSON.
Antes de escribir una sola línea de PHP, necesitas dominar las herramientas
básicas de comunicación.

> **¿No conoces `jq` todavía?** Se cubre en la lección 0.3, sección
> *"Inspeccionar y Validar JSON con jq"*. Léela antes de hacer el Paso 5.
> **¿Nunca has escrito un script bash?** La sección *"Validación Automática:
> Escribir un Script bash"* (también en la lección 0.3) explica el shebang,
> `set -euo pipefail` y los exit codes que pide el entregable.

## Instrucciones

Trabaja contra la API pública de JSONPlaceholder
(`https://jsonplaceholder.typicode.com`). Realiza cada paso dejando los
archivos de respuesta que se indican; tú decides los comandos exactos.

### Paso 1: GET simple

Haz un GET a `/posts/1` con el header `Accept: application/json` y guarda la
respuesta en `respuesta-get-post1.json`.

### Paso 2: GET con query params

Consulta `/posts?userId=1` (todos los posts del usuario 1) y guarda la
respuesta en `respuesta-get-filtered.json`.

### Paso 3: POST con datos

Haz un POST a `/posts` con `Content-Type: application/json` y un cuerpo que
represente un depósito inicial de una billetera (`title`, `body`, `userId`).
Guarda la respuesta en `respuesta-post.json`.

### Paso 4: Inspeccionar headers

Rehaz el GET del Paso 1 con la bandera `-v` (verbose). Identifica en la
salida: la línea de request, el status code y los headers de respuesta.

### Paso 5: Extraer un campo con jq

Haz un GET a `/users/1` y extrae el email del usuario 1 con `jq`, y también
`nombre`, `email` y `ciudad` en un solo objeto.

## Entregable

Un script `ejercicio-01.sh` (bash, con `#!/usr/bin/env bash` y
`set -euo pipefail`) que ejecute los 5 pasos, deje los archivos de respuesta
y termine imprimiendo el email extraído en el Paso 5.

## Verificación

- `respuesta-get-post1.json` es JSON válido y contiene el post 1.
- `respuesta-post.json` contiene un `id` asignado por el servidor.
- El email extraído con `jq` pertenece al usuario 1 (`Sincere@april.biz`).
- `bash ejercicio-01.sh` termina con exit code 0.

<details>
<summary>🔍 Ver solución de referencia</summary>

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=== Ejercicio 0.1: Peticiones HTTP ==="

# Paso 1: GET simple
curl -s -H "Accept: application/json" \
  "https://jsonplaceholder.typicode.com/posts/1" > respuesta-get-post1.json

# Paso 2: GET con query params
curl -s "https://jsonplaceholder.typicode.com/posts?userId=1" \
  > respuesta-get-filtered.json

# Paso 3: POST con datos
curl -s -X POST \
  -H "Content-Type: application/json" \
  -d '{"title":"Depósito inicial","body":"Primera transacción de mi billetera","userId":42}' \
  "https://jsonplaceholder.typicode.com/posts" > respuesta-post.json

# Paso 4: Inspeccionar headers con -v
curl -v -s -o /dev/null "https://jsonplaceholder.typicode.com/posts/1"

# Paso 5: Extraer campos con jq
EMAIL=$(curl -s "https://jsonplaceholder.typicode.com/users/1" | jq -r '.email')
echo "Email del usuario 1: ${EMAIL}"

curl -s "https://jsonplaceholder.typicode.com/users/1" \
  | jq '{nombre: .name, email: .email, ciudad: .address.city}'

echo "=== Completado ==="
```

**Salidas de referencia:**

```
Email del usuario 1: Sincere@april.biz
{
  "nombre": "Leanne Graham",
  "email": "Sincere@april.biz",
  "ciudad": "Gwenborough"
}
```
