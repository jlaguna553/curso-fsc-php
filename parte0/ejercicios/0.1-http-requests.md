# Ejercicio 0.1: Practicar Peticiones HTTP

## Objetivo

Familiarizarte con `curl` y los métodos HTTP fundamentales (GET, POST).

## Contexto

En PrestaFlow, los microservicios se comunican exclusivamente por HTTP/JSON.
Antes de escribir una sola línea de PHP, necesitas dominar las herramientas
básicas de comunicación.

## Instrucciones

### Paso 1: GET simple

Realiza un GET a la API pública de JSONPlaceholder:

```bash
curl -s -H "Accept: application/json" \
  https://jsonplaceholder.typicode.com/posts/1
```

Guarda la respuesta:

```bash
curl -s -H "Accept: application/json" \
  https://jsonplaceholder.typicode.com/posts/1 > respuesta-get-post1.json
```

### Paso 2: GET con query params

```bash
curl -s "https://jsonplaceholder.typicode.com/posts?userId=1" | python3 -c "
import json, sys
data = json.load(sys.stdin)
print(f'Posts del usuario 1: {len(data)}')
for post in data[:3]:
    print(f'  - [{post[\"id\"]}] {post[\"title\"][:50]}')
"
```

**Salida esperada:**

```
Posts del usuario 1: 10
  - [1] sunt aut facere repellat provident occaecati excepturi optio re...
  - [2] qui est esse
  - [3] ea molestias quasi exercitationem repellat qui ipsa sit aut
```

### Paso 3: POST con datos

```bash
curl -s -X POST \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Depósito inicial",
    "body": "Primera transacción de mi billetera",
    "userId": 42
  }' \
  https://jsonplaceholder.typicode.com/posts > respuesta-post.json
```

### Paso 4: Inspeccionar headers con -v

```bash
curl -v -s -o /dev/null https://jsonplaceholder.typicode.com/posts/1
```

**Salida esperada (truncated):**

```
* Host jsonplaceholder.typicode.com:443
> GET /posts/1 HTTP/2
> User-Agent: curl/8.7.1
> Accept: */*
< HTTP/2 200
< content-type: application/json; charset=utf-8
< x-powered-by: Express
< x-ratelimit-limit: 1000
```

### Paso 5: Extraer campo con jq

```bash
# Instalar jq si no lo tienes
# macOS: brew install jq
# Ubuntu: sudo apt install jq

curl -s https://jsonplaceholder.typicode.com/users/1 | jq '.email'
```

**Salida esperada:**

```
"Sincere@april.biz"
```

```bash
# Extraer múltiples campos
curl -s https://jsonplaceholder.typicode.com/users/1 | jq '{nombre: .name, email: .email, ciudad: .address.city}'
```

**Salida esperada:**

```json
{
  "nombre": "Leanne Graham",
  "email": "Sincere@april.biz",
  "ciudad": "Gwenborough"
}
```

## Entregable

Crea un archivo `ejercicio-01.sh` que ejecute todos los pasos y guarde los resultados:

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=== Ejercicio 0.1: Peticiones HTTP ==="

# Paso 1: GET
echo "Paso 1: GET simple"
curl -s "https://jsonplaceholder.typicode.com/posts/1" > respuesta-get-post1.json
echo "Guardado: respuesta-get-post1.json"

# Paso 2: GET con filtro
echo "Paso 2: GET con query param"
curl -s "https://jsonplaceholder.typicode.com/posts?userId=1" > respuesta-get-filtered.json
echo "Guardado: respuesta-get-filtered.json"

# Paso 3: POST
echo "Paso 3: POST con datos"
curl -s -X POST \
  -H "Content-Type: application/json" \
  -d '{"title":"Depósito inicial","body":"Primera transacción de mi billetera","userId":42}' \
  "https://jsonplaceholder.typicode.com/posts" > respuesta-post.json
echo "Guardado: respuesta-post.json"

# Paso 4: jq
echo "Paso 4: Extraer email con jq"
EMAIL=$(curl -s https://jsonplaceholder.typicode.com/users/1 | jq -r '.email')
echo "Email del usuario 1: ${EMAIL}"

echo "=== Completado ==="
```

## Verificación

```bash
bash ejercicio-01.sh

# Verificar outputs
cat respuesta-get-post1.json | python3 -c "import json,sys; d=json.load(sys.stdin); print(f'Title: {d[\"title\"][:50]}')"
# Salida: Title: sunt aut facere repellat provident occaecati excepturi...

cat respuesta-post.json | python3 -c "import json,sys; print(f'ID recibido: {json.load(sys.stdin)[\"id\"]}')"
# Salida: ID recibido: 101
```
