# Ejercicio 2.3: Application Services

## Objetivo

Crear los servicios de aplicación para crear billeteras y depositar.

## Instrucciones

1. Crear `CrearBilleteraService` con validación de moneda y usuario
2. Crear `RealizarDepositoService` con validación de saldo
3. Crear tests unitarios para ambos servicios
4. Verificar que los tests pasan

## Entregable

`src/Application/Service/CrearBilleteraService.php` + `RealizarDepositoService.php` + tests

## Verificación

```bash
./vendor/bin/phpunit tests/Unit/Application/ --testdox
```
