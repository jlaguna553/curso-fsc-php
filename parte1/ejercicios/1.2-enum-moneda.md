# Ejercicio 1.2: Crear el Enum Moneda

## Objetivo

Implementar el enum de monedas soportadas por PrestaFlow.

## Instrucciones

1. Crear `src/Domain/Moneda.php` como BackedEnum (string)
2. Agregar casos: MXN, USD, EUR
3. Implementar método `decimales(): int` que retorne 2
4. Implementar método `simbolo(): string` que retorne el símbolo
5. Crear tests que verifiquen: casos existen, decimales = 2, símbolos correctos

## Entregable

`src/Domain/Moneda.php` + `tests/Unit/Domain/MonedaTest.php`

## Verificación

```bash
./vendor/bin/phpunit tests/Unit/Domain/MonedaTest.php --testdox
```

## Puntos

| Criterio | Puntos |
|---|---|
| Enum es BackedEnum con string | 1 |
| Tiene 3 casos (MXN, USD, EUR) | 1 |
| decimales() retorna 2 | 1 |
| simbolo() retorna valor correcto | 1 |
| Tests pasan | 1 |
| **Total** | **5** |
