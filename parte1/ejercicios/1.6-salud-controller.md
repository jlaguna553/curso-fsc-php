# Ejercicio 1.6: SaludController

## Objetivo

Crear el health check endpoint del wallet-service.

## Instrucciones

1. Crear `src/Controller/SaludController.php`
2. Implementar GET /salud que retorne JSON con: servicio, estado, version, timestamp
3. Implementar GET /salud/readiness que retorne estado de readiness
4. Probar con curl y symfony serve

## Entregable

`src/Controller/SaludController.php` + verificación con curl

## Verificación

```bash
symfony serve -d public
curl -s https://127.0.0.1:8000/salud | jq '.estado'
# Salida: "ok"
```

## Puntos

| Criterio | Puntos |
|---|---|
| Endpoint GET /salud retorna 200 | 1 |
| Respuesta contiene servicio, estado, version, timestamp | 1 |
| Endpoint /salud/readiness funciona | 1 |
| Controller es delgado (sin lógica de negocio) | 1 |
| **Total** | **4** |
