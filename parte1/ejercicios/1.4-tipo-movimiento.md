# Ejercicio 1.4: Crear TipoMovimiento y Movimiento

## Objetivo

Implementar el enum de tipo de movimiento y el Value Object Movimiento.

## Instrucciones

1. Crear `src/Domain/TipoMovimiento.php` con casos DEPOSITO y RETIRO
2. Implementar `esAcreditacion(): bool` y `etiqueta(): string`
3. Crear `src/Domain/Movimiento.php` como Value Object readonly
4. Implementar factory methods: `deposito()` y `retiro()`
5. Crear tests para ambos

## Entregable

`src/Domain/TipoMovimiento.php` + `src/Domain/Movimiento.php` + tests

## Verificación

```bash
./vendor/bin/phpunit tests/Unit/Domain/MovimientoTest.php --testdox
```

## Puntos

| Criterio | Puntos |
|---|---|
| TipoMovimiento es enum con 2 casos | 1 |
| esAcreditacion() funciona correctamente | 1 |
| Movimiento es final readonly | 1 |
| Factory methods crean instancias correctas | 1 |
| Tests pasan | 1 |
| **Total** | **5** |
