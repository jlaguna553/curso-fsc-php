# Ejercicio 1.1: Crear el Symfony Skeleton

## Objetivo

Inicializar el wallet-service con las dependencias correctas y herramientas de calidad configuradas.

## Instrucciones

### Paso 1: Crear el proyecto

```bash
cd ~/fsc-php-curso
symfony new wallet-service --version=7.4.* --no-git
cd wallet-service
```

### Paso 2: Instalar dependencias de desarrollo

```bash
# PHPUnit 11: framework de testing
# PHPStan: análisis estático
# phpstan-symfony: extensiones de PHPStan para Symfony
# CS-Fixer: formateo de código
# PHPUnit Bridge: integración de PHPUnit con Symfony
# Maker Bundle: generación de código (opcional pero útil)
composer require --dev \
  phpunit/phpunit:^11.0 \
  phpstan/phpstan:^2.0 \
  phpstan/phpstan-symfony:^2.0 \
  php-cs-fixer/shim:^3.65 \
  symfony/phpunit-bridge:^7.4 \
  symfony/maker-bundle:^1.60
```

### Paso 3: Crear phpunit.xml.dist

Crear el archivo con la configuración de la plantilla de la Parte 1.

### Paso 4: Crear phpstan.neon

```yaml
includes:
    - vendor/phpstan/phpstan-symfony/extension.neon
parameters:
    level: 6
    paths:
        - src
        - tests
```

### Paso 5: Crear .php-cs-fixer.dist.php

Configurar con reglas `@PHP83Migration` y `@Symfony`.

### Paso 6: Crear Makefile

Targets: test, stan, fix, fix-check, ci, serve, clean, all, help.

### Paso 7: Verificar

```bash
make ci
# Debe pasar sin errores
```

## Entregable

wallet-service/ con make ci pasando.
