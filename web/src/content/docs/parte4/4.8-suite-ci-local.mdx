## Objetivo

Ejecutar TODA la suite de tests desde un solo comando.

## Instrucciones

1. Añade al `Makefile` el target:
   ```makefile
   test:  ## Ejecuta todas las suites de test
       ./vendor/bin/phpunit --testsuite unit --coverage-text
       ./vendor/bin/behat --format=pretty
   ```

2. Verifica que todo pasa con el comando único:
   ```bash
   docker compose exec php-fpm make test
   ```

3. Opcional: añade `test-unit` y `test-behat` por separado.

## Verificación

```bash
docker compose exec php-fpm make test
# Debe mostrar: OK (X tests), Behat: X passed
```

## Puntos: 4
