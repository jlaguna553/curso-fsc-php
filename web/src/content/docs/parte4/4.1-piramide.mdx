## Objetivo

Clasificar los tests existentes en la pirámide de testing.

## Instrucciones

Abre la carpeta `tests/` de tu wallet-service. Para cada archivo, clasifícalo en:

- **Unit/Domain**: lógica pura, sin dependencias externas
- **Unit/Application**: orquesta puertos (interfaces), puede usar mocks
- **Integration**: usa la BD real (PostgreSQL, Doctrine)
- **Functional**: simula peticiones HTTP (WebTestCase)
- **Architecture**: verifica estructura del código (namespace, dependencias)

Completa esta tabla:

| Archivo | Capa | ¿Por qué? |
|---|---|---|
| `tests/Unit/Domain/DineroTest.php` | ? | |
| `tests/Unit/Domain/BilleteraTest.php` | ? | |
| `tests/Unit/Application/CrearBilleteraCommandHandlerTest.php` | ? | |
| `tests/Integration/Repository/BilleteraRepositoryTest.php` | ? | |
| `tests/Functional/BilleteraControllerTest.php` | ? | |
| `tests/Architecture/DominioPuroTest.php` | ? | |
