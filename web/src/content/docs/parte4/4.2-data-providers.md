## Objetivo

Escribir tests parametrizados para cubrir muchos casos con un solo método.

## Instrucciones

1. Abre `tests/Unit/Domain/DineroDataProviderTest.php` (la solución de la lección 4.2).
2. Añade un **nuevo data provider** que pruebe la función `restar()`:
   ```php
   public static function proveerRestas(): array { ... }
   ```
   Debe cubrir al menos **4 casos**:
   - resta simple (10 - 3 = 7)
   - resta a cero (10 - 10 = 0)
   - resta por defecto (restar cero)
   - resta que lanza `FondosInsuficientes`

3. Escribe el test con `#[DataProvider('proveerRestas')]`.

## Verificación

```bash
./vendor/bin/phpunit --filter proveerRestas --testdox
# Debe mostrar 4+ tests verdes con descripciones del caso
```

## Puntos: 8
