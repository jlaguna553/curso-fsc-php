## Objetivo

Practicar Conventional Commits y el ciclo TDD básico con Git.

## Instrucciones

### Paso 1: Crear repositorio

```bash
mkdir mi-primer-repo && cd mi-primer-repo
git init
git branch -M main
```

### Paso 2: Primer commit (docs)

```bash
echo "Hola PrestaFlow" > hola.txt
git add hola.txt
git commit -m "docs: crear archivo de bienvenida"
```

### Paso 3: Segundo commit (feat) — TDD: primero el código

```bash
cat > suma.php << 'EOF'
<?php

declare(strict_types=1);

/**
 * Suma dos enteros.
 *
 * @param int $a Primer sumando
 * @param int $b Segundo sumando
 * @return int La suma de $a + $b
 */
function sumar(int $a, int $b): int
{
    return $a + $b;
}
EOF

git add suma.php
git commit -m "feat: crear función sumar"
```

### Paso 4: Tercer commit (test) — El test confirma que funciona

```bash
cat > test-suma.php << 'EOF'
<?php

declare(strict_types=1);

require 'suma.php';

// Test case 1: suma positiva
$resultado1 = sumar(2, 3);
$esperado1 = 5;
assert($resultado1 === $esperado1, "Esperaba $esperado1, obtuve $resultado1");

// Test case 2: suma con cero
$resultado2 = sumar(10, 0);
$esperado2 = 10;
assert($resultado2 === $esperado2, "Esperaba $esperado2, obtuve $resultado2");

// Test case 3: suma de negativos
$resultado3 = sumar(-5, -3);
$esperado3 = -8;
assert($resultado3 === $esperado3, "Esperaba $esperado3, obtuve $resultado3");

echo "✓ 3 tests pasaron correctamente" . PHP_EOL;
EOF

git add test-suma.php
git commit -m "test: agregar tests de la función sumar"
```

### Paso 5: Ejecutar el test

```bash
php test-suma.php
# Salida: ✓ 3 tests pasaron correctamente
```

### Paso 6: Cuarto commit (refactor) — Limpiar sin cambiar comportamiento

```bash
cat > suma.php << 'EOF'
<?php

declare(strict_types=1);

/**
 * Suma dos enteros de forma segura.
 *
 * @param int $a Primer sumando
 * @param int $b Segundo sumando
 * @return int La suma de $a + $b
 *
 * @throws \OverflowError Si la suma excede PHP_INT_MAX
 * @throws \UnderflowError Si la suma es menor que PHP_INT_MIN
 */
function sumar(int $a, int $b): int
{
    // Verificar overflow antes de la operación
    // Si $a > 0 y $b > PHP_INT_MAX - $a, habrá overflow
    if ($b > 0 && $a > PHP_INT_MAX - $b) {
        throw new \OverflowError("La suma de $a + $b excede PHP_INT_MAX");
    }

    // Verificar underflow antes de la operación
    if ($b < 0 && $a < PHP_INT_MIN - $b) {
        throw new \UnderflowError("La suma de $a + $b es menor que PHP_INT_MIN");
    }

    return $a + $b;
}
EOF

git add suma.php
git commit -m "refactor: agregar protección de overflow en función sumar"
```

### Paso 7: Verificar que los tests siguen pasando

```bash
php test-suma.php
# Salida: ✓ 3 tests pasaron correctamente (¡sigue pasando!)
```

### Paso 8: Ver el historial

```bash
git log --oneline --graph
```

**Salida esperada:**

```
* d2e3f4g refactor: agregar protección de overflow en función sumar
* c1d2e3f test: agregar tests de la función sumar
* b0a1b2c feat: crear función sumar
* a9z0a1b docs: crear archivo de bienvenida
```

## Entregable

Captura del historial de Git con al menos 4 commits con mensajes Convencionales.

## Puntos

| Criterio | Puntos |
|---|---|
| Al menos 4 commits | 1 |
| Commits usan formato Convencional | 2 |
| Test pasa exitosamente | 1 |
| Código usa `declare(strict_types=1)` | 1 |
| **Total** | **5** |
