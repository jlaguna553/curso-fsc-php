## Objetivo

Definir tus propios Commands y Queries como DTOs inmutables.

## Instrucciones

1. Crea `RealizarRetiroCommand` en `src/Message/Command/` siguiendo el modelo de
   `RealizarDepositoCommand`: `billeteraId`, `monto`, `moneda`, `descripcion`,
   `idempotencyKey` + factory `crear()` y método `claveUnica()`.
2. Crea `ListarBilleterasPorUsuarioQuery` en `src/Message/Query/` (campo `usuarioId`).
3. Añade el retiro a la API: endpoint `POST /api/v1/billeteras/{id}/retiro`
   (puedes dejarlo apuntando a un handler "TODO" por ahora).

## Verificación

```bash
./vendor/bin/phpunit --filter "Command|Query" --testdox
# Debe mostrar test de creación de mensajes (los que agregues)
```
