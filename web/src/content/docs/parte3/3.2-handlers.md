## Objetivo

Implementar y probar los use cases con las fachadas CommandBus/QueryBus.

## Instrucciones

1. Crea `src/Infrastructure/Bus/CommandBus.php` y `src/Infrastructure/Bus/QueryBus.php`
   con `HandleTrait` (copia el patrón de la lección 3.1).
2. Crea `RealizarRetiroCommandHandler` que:
   - Verifique idempotencia (misma clave = mismo resultado)
   - Delegue en `$billetera->retirar()`
   - Publique `TransaccionCompletadaEvent` con `tipo: "retiro"`
   - Retorne el balance nuevo
3. Traduce `FondosInsuficientes` a un HTTP 422 en el controller (no 400).

## Verificación (TDD: primero los tests, después el código)

```bash
./vendor/bin/phpunit tests/Unit/Application/ --testdox
# Esperado:
# ✅ Retiro con fondos suficientes retorna nuevo balance
# ✅ Retiro sin fondos lanza FondosInsuficientes
# ✅ Misma clave no duplica retiro
```
