## Objetivo

Verificar que el dominio es puro y cumple reglas de diseño.

## Instrucciones

1. Crear `tests/Architecture/DominioPuroTest.php`
2. Implementar test que verifique que src/Domain/ no importa Symfony
3. Implementar test que verifique que Value Objects son readonly
4. Implementar test que verifique que todos los archivos usan strict_types

## Entregable

`tests/Architecture/DominioPuroTest.php`

## Verificación

```bash
./vendor/bin/phpunit tests/Architecture/DominioPuroTest.php --testdox
```

## Puntos

| Criterio | Puntos |
|---|---|
| Test de dominio puro pasa | 2 |
| Test de readonly pasa | 1 |
| Test de strict_types pasa | 1 |
| **Total** | **4** |
