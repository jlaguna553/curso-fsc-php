## Objetivo

Crear documentación clara del wallet-service.

## Instrucciones

1. Crear `wallet-service/README.md` con:
   - Nombre y descripción del servicio
   - Stack tecnológico
   - Prerrequisitos
   - Instalación paso a paso
   - Cómo ejecutar tests
   - Cómo ejecutar el servidor de desarrollo
   - Estructura de directorios
   - API endpoints documentados
   - Licencia

## Entregable

`wallet-service/README.md`
