## Objetivo

Implementar el VO Dinero con el ciclo TDD completo: RED → GREEN → REFACTOR.

## Instrucciones

1. Crear `tests/Unit/Domain/DineroTest.php` con al menos 8 tests
2. Ejecutar tests → TODOS deben fallar (RED)
3. Crear `src/Domain/Dinero.php` con implementación mínima
4. Ejecutar tests → TODOS deben pasar (GREEN)
5. Refactorizar si es necesario (pero los tests deben seguir pasando)

## Tests Requeridos

- test_crear_dinero_desde_monto_decimal
- test_crear_dinero_desde_centavos
- test_crear_dinero_monto_negativo_lanza_excepcion
- test_crear_dinero_monto_no_numerico_lanza_excepcion
- test_sumar_montos_misma_moneda
- test_sumar_montos_distinta_moneda_lanza_excepcion
- test_restar_montos_suficientes
- test_restar_montos_insuficientes_lanza_fondos_insuficientes
- test_to_string_formateado
- test_conversion_centavos (con DataProvider)

## Entregable

`src/Domain/Dinero.php` + `tests/Unit/Domain/DineroTest.php` + commit con historial TDD

## Puntos

| Criterio | Puntos |
|---|---|
| Clase es final readonly | 1 |
| crear() valida monto no negativo | 1 |
| desdeCentavos() funciona correctamente | 1 |
| sumar() valida moneda igual | 1 |
| restar() lanza FondosInsuficientes | 1 |
| 10+ tests pasan | 1 |
| Historial muestra RED→GREEN | 1 |
| **Total** | **7** |
