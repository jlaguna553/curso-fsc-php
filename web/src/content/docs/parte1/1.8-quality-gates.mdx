## Objetivo

Configurar y ejecutar la pipeline completa de calidad.

## Instrucciones

1. Configurar PHPStan nivel 6
2. Configurar CS-Fixer con PSR-12 + PHP83Migration
3. Crear Makefile con targets: test, stan, fix, fix-check, ci
4. Ejecutar `make ci` y verificar que pasa

## Entregable

Archivos de configuración + Makefile + make ci pasando

## Verificación

```bash
make ci
# Debe mostrar: ✅ CI PASSED
```

## Puntos

| Criterio | Puntos |
|---|---|
| PHPStan configurado y pasa nivel 6 | 2 |
| CS-Fixer configurado y pasa dry-run | 2 |
| Makefile con targets esenciales | 1 |
| make ci ejecuta todo sin errores | 2 |
| **Total** | **7** |
