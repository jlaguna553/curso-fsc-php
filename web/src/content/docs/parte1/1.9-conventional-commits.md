## Objetivo

Documentar el historial correctamente con mensajes descriptivos.

## Instrucciones

1. Crear al menos 6 commits con mensajes Convencionales
2. El historial debe mostrar el ciclo TDD claramente
3. Usar tags de checkpoint

## Entregable

Historial de Git con al menos 6 commits y tag parte1

## Verificación

```bash
git log --oneline
# Debe mostrar al menos 6 commits con prefijos: feat, test, chore
```

## Puntos

| Criterio | Puntos |
|---|---|
| Al menos 6 commits | 1 |
| Commits usan formato Convencional | 2 |
| Historial muestra ciclo TDD | 1 |
| Tag parte1 existe | 1 |
| **Total** | **5** |
