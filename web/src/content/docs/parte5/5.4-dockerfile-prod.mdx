## Objetivo

Crear una imagen de producción multi-stage de `wallet-service`:
`builder` (con composer) → `runtime` (solo FPM + opcache, sin tooling).

## Instrucciones

1. Crea `docker/php-fpm/Dockerfile.prod` en `parte5/soluciones`.

2. **Stage `builder`**:
   - Base `composer:2`
   - Copia `composer.json` (y `composer.lock` si existe) y ejecuta
     `composer install --no-dev --prefer-dist --no-scripts --no-progress`

3. **Stage `runtime`**:
   - Base `php:8.3-fpm-alpine`
   - Instala SOLO lo necesario: `pdo_pgsql`, `opcache`, `pcntl`, `sockets` (RabbitMQ AMQP usa sockets)
   - Habilita opcache con configuración de producción (JIT opcional)
   - Copia `vendor/` desde `builder`
   - Copia el resto del código (`config/`, `src/`, `public/`, `migrations/`)
   - `CMD` por defecto: `php-fpm` (solo `-F` foreground)

4. La imagen NO debe incluir: composer, git, xdebug, bash.

## Verificación

```bash
docker build -f docker/php-fpm/Dockerfile.prod -t wallet-service:prod . 2>&1 | tail -3
# → Successfully tagged wallet-service:prod

docker run --rm wallet-service:prod which composer
# → composer: not found   (el tooling NO está en producción)

docker run --rm wallet-service:prod php -m | grep -E "pdo_pgsql|Zend OPcache"
# → pdo_pgsql y Zend OPcache presentes
```
