## Objetivo

Evitar spans duplicados en cada handler: crea un **decorador** `TraceableCommandBus` que envuelva el dispatch de TODO comando/query con un único span Datadog.

## Instrucciones

1. Crea `src/Infrastructure/Tracing/TraceableCommandBus.php` que implemente la MISMA interfaz que el `CommandBus` real (Parte 3 creó `App\Infrastructure\Bus\CommandBus` con `HandleTrait`).

2. El decorador recibe el bus real y el nombre de la operación como constructor args.

3. En `dispatch($mensaje)`:
   - abre un span con `name = 'bus.dispatch'` y `resource = get_class($mensaje)`
   - `meta`: `comando`, y si el mensaje tiene `billeteraId()`/`usuarioId()` accesibles, agrégalos
   - delega al bus real, cierra el span en `finally`
   - re-lanza excepciones

4. Alternativa sin reescribir la interfaz: haz que el decorador **componga** el bus real y exponga `dispatch($mensaje)` con la misma firma.

## Verificación

```bash
php -l src/Infrastructure/Tracing/TraceableCommandBus.php
# → No syntax errors detected

grep -E "trace_start_span|trace_close_span" src/Infrastructure/Tracing/TraceableCommandBus.php
# → presentes

grep -c "get_class" src/Infrastructure/Tracing/TraceableCommandBus.php
# → ≥ 1 (resource con el nombre real del comando)
```

Bono (+2 pts): crea `TraceableQueryBus` de la misma forma.
