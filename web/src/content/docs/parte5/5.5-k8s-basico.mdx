## Objetivo

Desplegar `wallet-service` en un clúster Kind con los tres recursos base:
`Namespace`, `Deployment` y `Service`.

## Instrucciones

1. Asegúrate de tener un clúster Kind:
   ```bash
   kind create cluster --name prestaflow
   ```

2. Crea en `parte5/soluciones/k8s/`:
   - `namespace.yaml`: `Namespace` `prestaflow` con labels `app: prestaflow`
   - `deployment.yaml`: `Deployment` `wallet-service`
     - 2 réplicas
     - imagen `wallet-service:prod` (usa `imagePullPolicy: IfNotPresent` para local)
     - `resources.requests`: cpu `100m`, memory `128Mi`
     - `resources.limits`: cpu `500m`, memory `256Mi`
     - `readinessProbe` y `livenessProbe` en `/api/salud` (puerto 9000 FPM)
     - env: `APP_ENV=prod`, `DATABASE_URL` (dnsname de postgres), `APP_SECRET`
   - `service.yaml`: `Service` `wallet-service`
     - selector → pods del deployment
     - puerto 80 → targetPort 9000

3. Aplica en orden:
   ```bash
   kubectl apply -f k8s/namespace.yaml
   kubectl apply -f k8s/deployment.yaml -n prestaflow
   kubectl apply -f k8s/service.yaml -n prestaflow
   ```

## Verificación

```bash
kubectl get pods -n prestaflow
# → 2 pods con STATUS Running y 2/2 READY (o 1/1 si solo hay un contenedor)

kubectl get svc -n prestaflow
# → wallet-service CLUSTER-IP asignada

kubectl rollout status deployment/wallet-service -n prestaflow
# → deployment "wallet-service" successfully rolled out
```
