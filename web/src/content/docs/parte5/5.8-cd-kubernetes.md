## Objetivo

Automatizar la entrega: en cada push a `main`, construir la imagen de
producción, subirla a GHCR y actualizar el Deployment en el clúster Kind.

## Instrucciones

1. Crea `.github/workflows/cd.yml` en `parte5/soluciones`:

   ```yaml
   name: CD
   on:
     push:
       branches: [ main ]
     workflow_dispatch:

   env:
     IMAGEN: ghcr.io/${{ github.repository }}/wallet-service

   jobs:
     entregar:
       runs-on: ubuntu-latest
       permissions:
         contents: read
         packages: write
       steps:
         - uses: actions/checkout@v4
         - uses: docker/login-action@v3
           with: { registry: ghcr.io, username: ${{ github.actor }}, password: ${{ secrets.GITHUB_TOKEN }} }
         - run: docker build -t $IMAGEN:latest -f docker/php-fpm/Dockerfile.prod .
         - run: docker push $IMAGEN:latest
   ```

2. Extensión GitOps-lite (bono, opcional): usa `kubectl` con un
   kubeconfig de tu clúster guardado como Secret en GitHub y:
   ```yaml
   - uses: azure/setup-kubectl@v4
   - run: kubectl set image deployment/wallet-service wallet=$IMAGEN:latest -n prestaflow
   ```

## Verificación

```bash
python3 -c "import yaml; yaml.safe_load(open('.github/workflows/cd.yml')); print('YAML OK')"
# → YAML OK

# Después del push a main:
#   Actions → CD → "entregar" → todas las steps ✅

# Si hiciste el bono, confirma el rollout:
kubectl rollout status deployment/wallet-service -n prestaflow
# → deployment "wallet-service" successfully rolled out
```
