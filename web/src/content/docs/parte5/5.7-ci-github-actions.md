## Objetivo

Automatizar la calidad del código en cada push/PR: el `ci.yml` corre
lint + PHPUnit + Behat + phpstan + fix-check (todo el `make ci` de la Parte 4).

## Instrucciones

1. Crea `.github/workflows/ci.yml` en `parte5/soluciones`:

   ```yaml
   name: CI
   on:
     push:
       branches: [ main ]
     pull_request:

   jobs:
     calidad:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: shivammathur/setup-php@v2
           with:
             php-version: '8.3'
             tools: composer
         - run: composer install --no-interaction --prefer-dist
         - run: make test
         - run: make stan
         - run: make fix-check
       services:
         postgres:
           image: postgres:16
           env:
             POSTGRES_PASSWORD: test
           ports: [ '5432:5432' ]
   ```

2. Nota: Behat no necesita BD real (usa el kernel en memoria), pero
   PHPUnit Integration/Functional (Parte 2) sí — por eso el servicio
   `postgres` está disponible.

## Verificación

```bash
# Desde GitHub (después del push):
#   Actions → CI → push → "calidad" → todas las steps ✅

# O localmente, validando el YAML:
python3 -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml')); print('YAML OK')"
# → YAML OK
```

El workflow DEBE ser el mismo que corre en tu máquina con `make ci`
(que ya pasó en los ejercicios de la Parte 4).

**`.github/workflows/ci.yml`**

```yaml
# .github/workflows/ci.yml — CALIDAD en cada push/PR
#
# CI (Continuous Integration): verifica que el código NUNCA rompe nada.
# Corre en cada push a main y en cada Pull Request.
#
# Esto ejecuta EXACTAMENTE la misma pipeline que `make ci` local
# (Parte 4): tests + mutation + phpstan + cs-fixer.
#
# Nota: el servicio postgres NO es usado por Behat (kernel en memoria),
# pero los tests Integration/Functional de la Parte 2 SÍ lo necesitan
# → lo declaramos como "services" y GitHub Actions lo levanta solo.
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  calidad:
    runs-on: ubuntu-latest

    # Servicio auxiliar: la BD PostgreSQL 16 para Integration/Functional
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_PASSWORD: test
          POSTGRES_DB: prestaflow_test
        ports:
          - '5432:5432'
        options: >-
          --health-cmd "pg_isready -U postgres"
          --health-interval 5s
          --health-timeout 5s
          --health-retries 5

    steps:
      # 1. Bajamos el código del PR/push
      - uses: actions/checkout@v4

      # 2. Preparamos PHP 8.3 + composer (el setup-php ya instala phpcov/pcov opcional)
      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.3'
          tools: composer
          coverage: pcov

      # 3. Instalamos dependencias (sin interacción)
      - run: composer install --no-interaction --prefer-dist

      # 4. Pipeline completa de calidad (Parte 4): unit + behat + cobertura
      - run: make test

      # 5. Análisis estático (Parte 1): nivel 6
      - run: make stan

      # 6. Estilo de código: falla si hay algo sin formatear
      - run: make fix-check
```

</details>
