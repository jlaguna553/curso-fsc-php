## Objetivo

Automatizar la calidad del código en cada push/PR: el `ci.yml` corre
lint + PHPUnit + Behat + phpstan + fix-check (todo el `make ci` de la Parte 4).

## Instrucciones

1. Crea `.github/workflows/ci.yml` en `parte5/soluciones`:

   ```yaml
   name: CI
   on:
     push:
       branches: [ main ]
     pull_request:

   jobs:
     calidad:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: shivammathur/setup-php@v2
           with:
             php-version: '8.3'
             tools: composer
         - run: composer install --no-interaction --prefer-dist
         - run: make test
         - run: make stan
         - run: make fix-check
       services:
         postgres:
           image: postgres:16
           env:
             POSTGRES_PASSWORD: test
           ports: [ '5432:5432' ]
   ```

2. Nota: Behat no necesita BD real (usa el kernel en memoria), pero
   PHPUnit Integration/Functional (Parte 2) sí — por eso el servicio
   `postgres` está disponible.

## Verificación

```bash
# Desde GitHub (después del push):
#   Actions → CI → push → "calidad" → todas las steps ✅

# O localmente, validando el YAML:
python3 -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml')); print('YAML OK')"
# → YAML OK
```

El workflow DEBE ser el mismo que corre en tu máquina con `make ci`
(que ya pasó en los ejercicios de la Parte 4).
