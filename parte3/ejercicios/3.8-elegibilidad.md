# Ejercicio 3.8 — Elegibilidad del loan-service (4 pts)

## Objetivo

Extender el motor de puntaje con una regla nueva usando TDD.

## Instrucciones

1. **Escribe primero el test** en `loan-service/tests/ElegibilidadReglaNuevaTest.php`:
   - Regla: los depósitos en USD suman +10 pts (mercado internacional)
2. Ejecuta el test y confirma que FALLA (RED):
   ```bash
   cd loan-service && ./vendor/bin/phpunit --filter ReglaNueva
   ```
3. Implementa la regla en `EvaluadorElegibilidad` (GREEN).
4. Ejecuta TODA la suite y confirma que nada se rompió:
   ```bash
   cd loan-service && composer test
   ```

## Verificación

```bash
./vendor/bin/phpunit --testdox
# Esperado: 6+ tests verdes (5 originales + 1 nuevo)
```

## Puntos: 4
