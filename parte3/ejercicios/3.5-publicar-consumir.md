# Ejercicio 3.5 — Publicar y consumir (10 pts)

## Objetivo

Demo full-stack: producir un evento real y consumirlo con el loan-service.

## Requisitos previos

- Parte 2 funcionando (PostgreSQL, wallet-service con billeteras)
- RabbitMQ levantado (ejercicio 3.3)

## Instrucciones

1. Instala el loan-service y su BD:
   ```bash
   docker compose exec postgres psql -U prestaflow -c \
     "CREATE DATABASE prestaflow_loan;"
   docker compose exec postgres psql -U prestaflow -d prestaflow_loan \
     -f /loan-service/config/schema.sql
   ```
2. Arranca el worker:
   ```bash
   cd loan-service && composer install && LOAN_DB_DSN="pgsql:host=localhost;port=5432;dbname=prestaflow_loan" \
     RABBITMQ_HOST=localhost php bin/consumir.php
   ```
3. En otra terminal, crea una billetera y deposita:
   ```bash
   curl -s -X POST localhost:8080/api/v1/billeteras \
     -H 'Content-Type: application/json' \
     -d '{"usuario_id":"ana","moneda":"MXN"}'

   curl -s -X POST localhost:8080/api/v1/billeteras/{ID}/deposito \
     -H 'Content-Type: application/json' \
     -d '{"monto":"15000.00","moneda":"MXN","descripcion":"Nómina","idempotency_key":"k-1"}'
   ```

## Resultado esperado

```text
[2026-09-10T12:00:01Z] INFO  loan-service escuchando. Cola: loan_events
[2026-09-10T12:00:07Z] INFO  Evento evt-... → APROBADO (puntaje 85)
```

Y en la BD de resultados:

```bash
docker compose exec postgres psql -U prestaflow -d prestaflow_loan -c \
  "SELECT event_id, puntaje, recomendacion FROM eventos_procesados;"
```
