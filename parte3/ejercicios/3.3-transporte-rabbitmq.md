# Ejercicio 3.3 — Configurar transporte RabbitMQ (6 pts)

## Objetivo

Conectar Messenger con RabbitMQ usando el serializador contract-first.

## Instrucciones

1. Copia `config/packages/messenger.yaml` (lección 3.3):
   - buses: `command.bus`, `query.bus`, `event.bus`
   - transports: `events` (AMQP) y `failed` (Doctrine)
2. Añade a `.env`:
   ```env
   MESSENGER_TRANSPORT_DSN=amqp://prestaflow:secret@rabbitmq:5672/%2f
   ```
3. Añade al `docker-compose.yml` el servicio `rabbitmq` (si no lo tienes de la Parte 2):
   ```yaml
   rabbitmq:
       image: rabbitmq:3.13-management-alpine
       environment:
           RABBITMQ_DEFAULT_USER: prestaflow
           RABBITMQ_DEFAULT_PASS: secret
       ports:
           - "5672:5672"
           - "15672:15672"
   ```

## Verificación

```bash
docker compose up -d rabbitmq && docker compose ps | grep rabbitmq
# Estado: Up (healthy)

php bin/console debug:messenger
# Debe listar: command.bus, query.bus, event.bus, transports events y failed

# Salud de la conexión: publica un evento de prueba y mira en la UI
open http://localhost:15672   # prestaflow / secret → cola "wallet_events"
```
