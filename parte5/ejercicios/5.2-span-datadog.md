# Ejercicio 5.2 — Span personalizado Datadog en handlers (8 pts)

## Objetivo

Instrumentar `RealizarDepositoCommandHandler` con un **span Datadog** que mida la operación completa y aterrice tags útiles.

## Instrucciones

1. Usa la API de tracing de ddtrace (`DD\trace_start_span()` / `DD\trace_close_span()`).

2. Configura el span:
   - `name`: `deposito.procesar`
   - `resource`: id de la billetera
   - `meta`: `usuario`, `monto`, `moneda`, `resultado`

3. En caso de excepción: `resultado: error` Y `exception: <mensaje>`, y **re-lanza** (no te tragues el error).

4. Usa `finally` para cerrar el span garantizado (si el handler lanza, el span se cierra igual).

## Pistas

```php
$span = DD\trace_start_span();
$span->name = 'deposito.procesar';
// ... lógica ...
$span->meta['resultado'] = 'exito';
DD\trace_close_span();
```

`DD\trace_start_span()` NO requiere que el agente esté activo: si
`DD_TRACE_ENABLED=false`, las llamadas son no-op (tu test sigue pasando).
